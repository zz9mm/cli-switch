# 复制配置档

## 目标

通过独立的复制操作快速创建现有配置的副本，避免将“复制”混入新建配置档的内容录入流程。

## 入口

默认入口是运行 `clis` 后依次选择“Claude Code”和“复制配置档”。

可选的非交互入口为：

```bash
# 将当前生效的 Claude Code 配置复制为配置档
clis claude copy current <新名称>

# 将已有配置档复制为另一份配置档
clis claude copy <来源名称> <新名称>
```

## 引导流程

1. 选择来源：“当前 Claude Code 配置”或一个已有配置档。
2. 输入新配置档名称。
3. 显示来源配置摘要和目标名称，要求确认。
4. 校验来源 JSON 后，以新的元数据写入目标配置档。

## 数据与安全

- 复制是深拷贝；后续编辑目标配置档不会修改来源。
- 目标名称不可覆盖既有配置档，除非用户在显式覆盖确认流程中同意。
- 复制当前配置时只读取 `~/.claude/settings.json`，不读取认证凭据文件。
- 配置内容中的 API Key 不输出到终端，目标文件沿用 `0600` 权限。

## 验收标准

- 能从当前配置和既有配置档两种来源完成复制。
- 来源与目标 JSON 内容相同，但元数据中的名称、创建时间各自独立。
- 复制失败或取消时，来源和目标均不被修改。
