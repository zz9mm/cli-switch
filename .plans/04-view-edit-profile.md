# 查看与编辑配置档

## 目标

提供引导式查看和编辑能力，让用户能检查配置摘要，并在需要高级字段时直接编辑 JSON。

## 入口

默认入口是运行 `clis` 后依次选择“Claude Code”和“查看/编辑配置档”。

可选的非交互入口为：

```bash
clis claude show <名称>
clis claude edit <名称>
```

## 引导流程

1. 从列表选择一个配置档。
2. 显示摘要：名称、API URL、模型、创建时间和最近使用时间；API Key 始终脱敏。
3. 选择后续操作：返回、在编辑器中编辑 JSON，或使用 API 引导更新 API URL、API Key 和模型。
4. 编辑后展示脱敏预览，确认后校验 JSON 并原子替换原配置档。

## 数据与安全

- JSON 编辑使用临时文件，只有确认且 JSON 校验通过时才覆盖原配置档。
- 取消编辑、编辑器异常退出或 JSON 无效时保留原文件。
- API Key 输入采用无回显方式；显示、日志和错误文本不能包含完整密钥。
- 编辑后保持目录 `0700` 与配置文件 `0600` 权限。

## 验收标准

- 用户可在不暴露密钥的情况下查看配置档关键信息。
- 用户可通过引导更新 API URL、API Key、模型，也可通过 JSON 编辑高级字段。
- 无效 JSON 无法保存，且原配置档保持不变。
