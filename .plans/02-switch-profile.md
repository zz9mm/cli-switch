# 切换配置档

## 目标

从现有 Claude Code 配置档中选择一项，并安全地应用为当前生效配置。

## 入口

默认入口是运行 `clis` 后依次选择“Claude Code”、“切换配置档”和目标配置档。

可选的非交互入口为：

```bash
clis claude use <名称>
```

## 引导流程

1. 列出全部配置档，显示名称、模型、API URL 主机名和最近使用时间，不显示 API Key。
2. 用户通过方向键或编号选择目标配置档。
3. 显示将要应用的配置摘要，并询问确认。
4. 校验配置档的 `settings.json` 后，备份当前 `~/.claude/settings.json`。
5. 采用临时文件与原子重命名写入目标配置，并更新当前配置档状态。

## 数据与安全

- 写入前校验配置档 JSON，遇到损坏配置立即停止。
- 备份保存于 `~/.config/clis/claude/backups/`，保留创建时间以便恢复。
- 写入失败时保留原有 Claude Code 配置，不得留下截断文件。
- 状态文件仅记录当前配置档名称和应用时间，不记录密钥。

## 验收标准

- 用户能在引导菜单中完成配置档切换。
- 每次成功切换前都有可恢复的旧配置备份。
- `clis claude current` 能显示当前由 `clis` 应用的配置档。
