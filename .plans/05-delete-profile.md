# 删除配置档

## 目标

在明确确认后删除一个不再使用的配置档，并防止误删当前正在使用的配置档。

## 入口

默认入口是运行 `clis` 后依次选择“Claude Code”和“删除配置档”。

可选的非交互入口为：

```bash
clis claude delete <名称>
```

## 引导流程

1. 从配置档列表选择待删除项。
2. 显示名称、模型和 API URL 主机名作为二次核对信息。
3. 若其为当前由 `clis` 应用的配置档，说明删除不会修改已写入 Claude Code 的配置，但必须再次确认。
4. 要求用户输入配置档名称确认删除。
5. 删除配置档目录并更新当前状态记录（如适用）。

## 数据与安全

- 仅允许删除配置档根目录下经名称校验解析得到的目标目录，禁止路径穿越。
- 不删除 `~/.claude/settings.json`，也不删除切换时生成的备份。
- 非交互模式必须传入 `--yes` 才能实际删除；否则只提示确认要求。
- 删除完成后不输出任何 API Key 或完整配置内容。

## 验收标准

- 用户必须经过明确确认才能删除配置档。
- 删除当前配置档不会影响此刻 Claude Code 的已生效配置。
- 删除指定配置档后，其余配置档和备份保持完整。
